MARJORIE NICHAELLA ODIONG - PERSONAL PORTFOLIO

Files:

- style.css: layout, colors, and responsive design

1. Extract the ZIP file.
2. Open the Marjorie_Portfolio folder.
3. Double-click index.html. It will open in your browser.
